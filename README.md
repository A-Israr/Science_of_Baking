# Science of Baking

A personal baking + science blog created as a self-built web development project. The goal of this website is to explore baking from both a practical and scientific perspective while learning and applying fundamental front-end development concepts.

## 🧁 Features

### 🧭 Sticky Navigation Bar  
- Stays fixed at the top while scrolling  
- Provides quick access to main pages  

### 🖼️ Clickable Hero Image  
- Responsive hero image at the top of the homepage  
- Clickable element that can direct users to posts or other sections  

### 🍪 Featured Posts Section  
- Highlighted content area with preview summaries  
- Structured layout for post cards with images, titles, and brief descriptions  

### 👩‍🍳 About Preview Section  
- Short intro text on the homepage  
- Includes link to full About Me page  

### 📄 About Page  
- Full written description of the author and purpose of blog  

### 🦶 Footer  
- Persistent footer for branding and closure  
- Light, friendly sign-off tone  

---

## 🛠️ Tech Used

- **CSS3** – for styling and responsiveness
